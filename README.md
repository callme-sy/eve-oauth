# Privacy Policy — Eve (personal OAuth client)

Last updated: 2026-09-24

This OAuth client is a **personal tool** used solely by its developer to let a self-hosted personal assistant ("Eve") access his own Google Workspace data.

**What is accessed:** Gmail (read, send, modify), Google Calendar, Google Drive, Google Docs, Google Sheets, and Google Contacts, limited to the account that consents.

**Where the data goes:** all data is processed and stored on a self-hosted server located in the developer's home in France. Nothing is sold, shared with third parties, or used for advertising or model training. Data is never forwarded to any external service other than Google APIs themselves.

**Who can consent:** only the developer's own Google account. This application is not offered to the public.

**Revocation:** consent can be revoked at any time at https://myaccount.google.com/permissions.

**Contact:** see the repository owner profile on GitHub.


This repository hosts the privacy policy for the personal OAuth client named "Eve".
